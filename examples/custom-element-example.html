temporal-datetimerange-picker — custom element example

The classic new DateRangePicker(...) constructor and the declarative <temporal-date-range-picker> tag are the same engine underneath — this page only uses the tag.

1. Attribute-only configuration

Everything set via HTML attributes: time-picker, opens="left", show-week-numbers.

<temporal-date-range-picker
    id="dtr-attrs"
    time-picker opens="left"
    show-week-numbers>
</temporal-date-range-picker>

2. Opting out of a default-true option

linked-calendars="false" and auto-update-input="false" — boolean attributes here use presence + an explicit ="false" to opt out of defaults.

<temporal-date-range-picker
    id="dtr-unlinked"
     linked-calendars="false"
     auto-update-input="false">
</temporal-date-range-picker>

3. Custom locale via attributes

format, separator, apply-label, cancel-label attributes.

<temporal-date-range-picker 
    id="dtr-locale" 
    format="DD/MM/YYYY" 
    separator=" au " 
    apply-label="Appliquer" 
    cancel-label="Annuler">
</temporal-date-range-picker>

4. Provided your own <input>

A child <input> is adopted instead of the element creating its own.

<temporal-date-range-picker 
    id="dtr-owninput">
    <input type="text"
        placeholder="pick a range…">
</temporal-date-range-picker>

5. JS properties: ranges, isInvalidDate

.ranges, .isInvalidDate set as JS properties before the element connects.

<temporal-date-range-picker
    id="dtr-props">
</temporal-date-range-picker>

6. Escape hatch: .picker

Calling .picker.setStartDate(...) directly on the underlying DateRangePicker instance, plus the element's own .setStartDate() convenience method.

<temporal-date-range-picker 
    id="dtr-escape">
</temporal-date-range-picker>
