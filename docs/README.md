# Documentation

More detailed installation and usage guides than the [main README](../README.md). Start here:

- **[Installation](install.md)** — getting the JS/CSS (and the Astro component) into your project, via CDN or by downloading the files yourself.
- **[JavaScript usage](usage-js.md)** — using the picker in a plain HTML/JavaScript page, either the `new DateRangePicker(...)` function or the `<temporal-date-range-picker>` custom element. Includes a Quick Start.
- **[Astro usage](usage-astro.md)** — using the `<TemporalDateRangePicker />` component in an Astro or Astro Starlight project.

New here? Read [Installation](install.md) first, then jump to whichever usage guide matches what you're building.

This `docs/` folder is intentionally small for now — more guides may be added here as the project grows.
